# Chalk & Bar website

Static pages for the App Store: `index.html`, `support.html` (Support URL), `privacy.html` (Privacy Policy URL).

Publish with GitHub Pages:
1. Create a **public** repository named `chalk-and-bar` on GitHub.
2. Upload these files to it (Add file → Upload files).
3. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, folder `/ (root)` → Save.
4. After a minute the site is at `https://YOUR-GITHUB-NAME.github.io/chalk-and-bar/`.

Before publishing, replace `chalkandbar.app@gmail.com` with your support address in `support.html` and `privacy.html`.
